# Landing Page

Repositorio destinado exclusivamente al portal público e informativo del sistema Simple Stock Flow.

## Características
- Compuesto de artefactos estáticos (HTML, CSS, Assets).
- Evita de manera deliberada la inyección de frameworks pesados de frontend o lenguajes de servidor.
- Totalmente independiente del ecosistema central, destinado a un despliegue puramente estático.
